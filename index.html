About Me

I am an Associate Professor and Researcher at the University of Mustapha Stambouli in Mascara, Algeria. My work is dedicated to solving complex problems in Software Engineering and Information Security by leveraging the power of Machine Learning and Deep Learning.

With a PhD in Computer Science and extensive experience in both academia and systems engineering, I focus on developing innovative, automated solutions for software vulnerability prediction and maintenance.

Research Interests

Vulnerability Prediction

Using code metrics and deep learning to identify security flaws at a fine-grained level, assisting developers in securing software systems.

NLP for Code

Applying NLP techniques like Word Embeddings and TF-IDF to extract semantic insights from source code for improved analysis.

Software Evolution

Developing hybrid models to predict software co-changes and improve system reliability during maintenance.
